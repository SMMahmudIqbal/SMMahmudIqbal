### Focus

- **Preservation Kinetics**: Arrhenius degradation kinetics ($Q_{10}$), sorption isotherms ($A_w$), and barrier packaging simulations.
- **Air-Gapped Systems**: Privacy-first, zero-network Android architecture with native Scoped Storage pipelines.
- **Latent Manifolds & 3D WebGL**: High-dimensional semantic graph projection (t-SNE/UMAP/PCA), Three.js hardware instancing.
- **Kinetic Interfaces**: High-contrast editorial systems, motion graphics, and canvas dynamic simulations.
